## Proje Açıklaması
Bu proje, React Native kullanılarak geliştirilmiş, yeniden kullanılabilir bileşenler (components) içeren bir profil kartı uygulamasıdır. `ScrollView`, `SafeAreaView` ve `TouchableOpacity` gibi temel yapılar kullanılmıştır.

## Proje Yapısı [cite: 212]
- **App.js:** Uygulamanın ana giriş noktasıdır. Verileri listeler ve düzeni sağlar.
- **components/ProfileCard.js:** Profil kartı bileşeni. Resim, isim, rol ve tıklama olayını yönetir.
- **assets/:** Uygulamada kullanılan profil resimlerini (ada.png, grace.png, hedy.png) içerir.
